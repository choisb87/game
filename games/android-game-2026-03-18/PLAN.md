# Shadow Dungeon — 게임 디자인 문서

## 핵심 컨셉

**"한 손 로그라이크 던전 크롤러"** — 스와이프 한 번이 한 턴. 움직일 때마다 세상이 반응한다.

## 30초 훅 (Fun Loop)

1. **0~5초**: 스와이프로 이동 → 즉시 직관적 조작 이해
2. **5~15초**: 첫 번째 적 발견 → 걸어가서 공격 → 전투 피드백 (파티클, 데미지 수치, 화면 흔들림)
3. **15~25초**: 아이템 획득 → 무기로 공격력 UP → 성장 쾌감
4. **25~30초**: 계단 발견 → "더 내려갈까?" → 탐험 욕구 자극

## 핵심 루프

```
던전 진입 → 탐험 → 전투 → 아이템 수집 → 계단 하강 → 반복
                                                    ↓ (사망)
                                              기록 갱신 → 재도전
```

## 리텐션 메커니즘

### 단기 (세션 내)
- **전장의 안개**: 탐험 욕구 자극 — "이 방에는 뭐가 있을까?"
- **턴 기반 긴장감**: 매 이동이 전략적 결정
- **레벨업 쾌감**: XP 축적 → 스탯 증가 → 눈에 보이는 성장
- **몬스터 다양성**: 층별 새로운 적 등장 → 패턴 학습 동기

### 중기 (세션 간)
- **최고 기록 갱신**: 최고 층수 / 최고 점수 → "이번엔 더 깊이"
- **누적 통계**: 총 탐험 횟수, 베스트 기록
- **절차적 생성**: 매번 다른 던전 → 반복해도 신선

### 장기
- **적 계층 구조**: 8종의 몬스터 × 층별 스케일링 → 끝이 보이지 않는 깊이
- **아이템 조합**: 무기+방패+포션+두루마리 → 빌드 다양성

## 유료 앱 정당성 ($2.99)

### 왜 유료인가
1. **광고 없음**: 턴 기반 게임의 몰입을 깨는 광고 배제
2. **조작감 보호**: 배너가 없는 풀스크린 → 오터치 방지
3. **완전한 경험**: 모든 콘텐츠 즉시 접근, 잠금/과금 없음
4. **로그라이크 팬 타겟**: 장르 팬은 $2.99에 망설이지 않음

### 가치 제안
- 무한 리플레이 (절차적 생성)
- 한 손 조작 → 출퇴근/대기 중 최적
- 외부 의존성 없음 → 오프라인 완전 플레이
- 가볍고 배터리 친화적

## 비주얼 디자인

### 색상 팔레트
- **배경**: 짙은 남색 (#0A0E17)
- **플레이어**: 밝은 시안 (#4FC3F7) — 어둠 속 유일한 빛
- **적**: 붉은 계열 (#EF5350~FF1744) — 위험 시각 신호
- **아이템**: 따뜻한 색 (금, 주황, 핑크) — 보상 시각 신호
- **계단**: 보라 (#7E57C2) — 목표 강조

### 시각 효과
- 전장의 안개 (레이캐스팅 기반 시야)
- 파티클 이펙트 (전투, 아이템 획득)
- 플로팅 텍스트 (데미지/힐 수치)
- 화면 흔들림 (피격)
- 비네트 효과 (분위기 강화)
- 적/아이템 맥동 애니메이션

## 기술 아키텍처

- **불변 상태**: 모든 게임 상태는 `data class`, `copy()`로 갱신
- **순수 함수**: 게임 로직은 부수효과 없음
- **Canvas 렌더링**: Compose Canvas API 직접 사용
- **60fps 루프**: `LaunchedEffect` + `withFrameNanos`
