# Market Benchmark — Shadow Dungeon

## 벤치마크 대상 (모바일 로그라이크/던전 크롤러)

### 1. Shattered Pixel Dungeon
- **장르**: 전통 로그라이크 던전 크롤러
- **가격**: 무료 (오픈소스), 기부 모델
- **강점**: 깊은 게임플레이, 활발한 커뮤니티, 지속적 업데이트
- **약점**: PC 로그라이크 UX를 거의 그대로 가져와서 모바일 조작 불편
- **채택**: 턴 기반 던전 크롤러의 기본 구조
- **회피**: 복잡한 인벤토리/조합 시스템 → 모바일에서 번거로움

### 2. Dungeon Cards
- **장르**: 카드 기반 던전 크롤러
- **가격**: 무료 (광고+IAP)
- **강점**: 극도로 간결한 조작, 한 손 플레이, 빠른 세션
- **약점**: 깊이 부족, 반복 플레이 시 단조로움
- **채택**: 한 손 조작 철학, 3~5분 세션 길이
- **회피**: 지나친 단순화 → 전략 깊이 상실

### 3. Hoplite
- **장르**: 턴 기반 전술 로그라이크
- **가격**: 무료 / 프리미엄 $2.99
- **강점**: 미니멀하지만 전략적, 깔끔한 비주얼
- **약점**: 콘텐츠 양이 적음
- **채택**: 미니멀 디자인 + 전략 깊이의 균형
- **회피**: 콘텐츠 부족 → 8종 몬스터 + 11종 아이템으로 보완

### 4. Slay the Spire (Mobile)
- **장르**: 덱빌딩 로그라이크
- **가격**: $9.99
- **강점**: 무한 리플레이성, 전략 깊이
- **약점**: 세션이 길고 모바일 최적화 부족
- **채택**: 매 런마다 다른 경험 (절차적 생성)
- **회피**: 긴 세션 → 3~10분으로 제한

### 5. Soul Knight
- **장르**: 액션 로그라이크 슈터
- **가격**: 무료 (IAP)
- **강점**: 빠른 액션, 다양한 무기, 멀티플레이
- **약점**: 조작 복잡, 쌍 조이스틱 필요
- **채택**: 다양한 무기/아이템 시스템
- **회피**: 듀얼 스틱 → 스와이프 한 손 조작

## 시장 포지셔닝

```
        깊이 ↑
        │
  Shattered PD ●         ● Slay the Spire
        │
        │     ★ Shadow Dungeon
        │
  Hoplite ●
        │
        │         ● Soul Knight
  Dungeon Cards ●
        │
        └──────────────────────→ 접근성
```

**Shadow Dungeon의 위치**: Hoplite의 미니멀 전략성 + Dungeon Cards의 접근성 + Shattered PD의 콘텐츠 깊이

## 차별화 요소

| 경쟁작 | Shadow Dungeon 차별점 |
|--------|----------------------|
| Shattered PD | 더 간결한 조작 (스와이프 only) |
| Dungeon Cards | 더 깊은 전략 (공간 기반 전투) |
| Hoplite | 더 많은 콘텐츠 (8종 적, 11종 아이템) |
| Soul Knight | 한 손 조작 가능, 턴 기반으로 사고할 시간 |

## 핵심 채택 원칙

1. **한 손 조작**: 스와이프만으로 모든 것
2. **짧은 세션**: 3~10분 완결
3. **시각적 피드백**: 파티클, 흔들림, 플로팅 텍스트
4. **오프라인 완전 플레이**: 서버 의존 없음
5. **프리미엄 모델**: 광고 제거로 몰입 보호
