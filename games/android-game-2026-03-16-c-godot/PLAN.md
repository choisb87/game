# PLAN

## 목표

`Glass Garden`와 완전히 다른 장르의 Godot 프로젝트를 만든다. 퍼즐 대신 즉시 손맛이 오는 세로형 슈터를 선택하고, 상용 모바일 게임처럼 보이는 화면 흐름과 시각 피드백을 우선한다.

## 방향

- 장르 전환: 퍼즐 -> 아케이드 슈터
- 구조 전환: 단일 화면 중심 -> 메뉴 / 게임 / 결과 분리
- 감각 강화: 드래그 이동, 자동 사격, 연쇄 점수, 폭발, 오버드라이브
- 모바일 우선: 세로 화면, 한 손 입력, 큰 버튼, 짧은 런

## 구현 범위

- 완료: `project.godot` 신규 구성
- 완료: `scenes/Main.tscn`
- 완료: `scenes/MenuScene.tscn`
- 완료: `scenes/GameScene.tscn`
- 완료: `scenes/ResultScene.tscn`
- 완료: 전장 로직 `scripts/battlefield.gd`
- 완료: 공유 배경 연출 `scripts/neon_backdrop.gd`
- 완료: 최고 기록 저장 로직
- 완료: 한국어 문서 및 메타데이터

## 설계 결정

- 외부 리소스를 최소화하고 드로잉 기반 연출을 사용해 자기완결형 프로토타입으로 유지한다.
- 한 번의 런을 45초로 제한해 모바일에서 즉시 다시 시도하기 쉬운 템포를 만든다.
- 결과 씬에서 랭크, 최고 점수, 재출격 버튼을 전면에 배치해 반복 플레이 이유를 만든다.
