# Neon Striker

`Neon Striker`는 세로형 모바일 플레이를 전제로 만든 짧은 런 기반 사이버 슈터 프로토타입입니다. 퍼즐 중심이었던 `Glass Garden`와 달리, 이번 프로젝트는 `메뉴 -> 출격 -> 결과`의 상용형 루프와 즉시 체감되는 전투 감각에 집중했습니다.

## 게임 개요

- 장르: 세로형 아케이드 슈터
- 플레이 길이: 1회 약 45초
- 핵심 조작: 화면 드래그 이동 + 자동 사격 + `OVERDRIVE` 버튼
- 핵심 재미: 회피, 연쇄 점수, 에너지 드롭 회수, 짧고 강한 폭발 피드백

## 플레이 흐름

1. 메뉴 화면에서 최고 기록과 조작 요약을 확인합니다.
2. `출격 시작`으로 게임 씬에 진입합니다.
3. 기체를 드래그로 움직이며 적 편대를 회피하고 자동 사격으로 격추합니다.
4. 에너지 셀을 모아 `OVERDRIVE`를 충전하고 난전 구간에서 폭발적으로 사용합니다.
5. 45초를 버티거나 격추되면 결과 씬으로 이동합니다.
6. 결과 화면에서 랭크, 점수, 격추 수, 최고 기록 갱신 여부를 확인하고 재출격 또는 메뉴 복귀를 선택합니다.

## 구성 포인트

- `MenuScene`, `GameScene`, `ResultScene`를 분리해 상용 게임앱 같은 화면 흐름을 만듭니다.
- 배경, 전장, 적, 탄, 폭발을 절반 이상 절차적으로 그려 외부 에셋 의존도를 낮췄습니다.
- 화면 하단 큰 버튼과 전체 드래그 입력을 사용해 모바일 한 손 플레이를 우선했습니다.
- 최고 점수는 `user://neon_striker.save`에 저장되도록 설계했습니다.

## 실행 방법

1. Godot 4.2 이상에서 이 폴더를 Import 합니다.
2. 메인 씬은 `res://scenes/Main.tscn`입니다.
3. 에디터의 Play 버튼으로 실행합니다.

## Android 고려 사항

- 세로 화면(`1080x1920`) 기준으로 설계했습니다.
- 모바일 렌더러를 사용하도록 `project.godot`을 설정했습니다.
- 조작은 터치 드래그와 큰 액션 버튼 중심으로 배치했습니다.
- 런 타임 중 텍스처보다 드로잉 기반 연출 비중이 높아 초기 이식 부담이 낮습니다.

## 현재 범위

- 사운드, 햅틱, 실제 Android export preset 파일은 포함하지 않았습니다.
- Godot 실행 파일이 없는 환경이어서 에디터 실행 검증은 하지 못했고, 대신 텍스트 기반 검증과 참조 무결성 확인을 수행했습니다.
