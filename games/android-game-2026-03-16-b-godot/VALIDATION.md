# VALIDATION

## 이번 작업에서 확인한 항목

- `scenes/Main.tscn`이 메뉴 오버레이, 퍼즐 보드, 결과 카드, 하단 액션 패널을 모두 포함하는지 확인했습니다.
- `scripts/main.gd`, `scripts/board_view.gd`, `scripts/background_layer.gd`에 대해 `gdlint` 정적 검사를 통과했습니다.
- `Main.tscn`이 참조하는 `res://` 스크립트 경로가 모두 실제 파일로 존재함을 확인했습니다.
- 5개 레벨을 간단한 브루트포스 스크립트로 검사해 모두 제한 회전 수 안에 해법이 있음을 확인했습니다.

## 퍼즐 해법 검사 결과

- `새벽 온실`: 최소 2회전, 제한 4회전
- `호박빛 아치`: 최소 2회전, 제한 5회전
- `유리 회랑`: 최소 3회전, 제한 6회전
- `이중 채광실`: 최소 3회전, 제한 6회전
- `황혼 보존동`: 최소 3회전, 제한 7회전

## 실행 환경 한계

- 이 환경에는 `godot4` 또는 `godot` 실행 파일이 없어 `--headless` 실제 실행 검증은 수행하지 못했습니다.
- 따라서 이번 검증은 스크립트 린트, 씬 참조 점검, 레벨 해법 검사까지 수행한 상태입니다.

## 서브 리뷰 (게임플레이 명확성 / 첫 1분 재미 / 폴리시)

**적용된 수정:**
- 꽃(bloom) 크기 33% 확대 — 목표 오브젝트 시인성 향상 (core 0.075→0.10, petal 0.09/0.13→0.11/0.16, glow 0.22→0.28)
- 탭 펄스 0.32s→0.42s — 터치 피드백 인지 개선
- 레벨 클리어 시 보드 전체 골든 플래시(0.55s) 추가 — 성공 모먼트 강화
- 레벨 1 힌트를 "거울 탭→90° 회전" 조작 안내로 구체화 — 온보딩 개선

**미적용 관찰 사항 (향후 개선 후보):**
- 광원 진입 방향을 나타내는 작은 화살표 아이콘 추가 (현재 점만 표시)
- 빈 칸 반복 탭 시 피드백 메시지 축약 (두 번째부터 짧게)
- 레벨 1에서 첫 탭 전 자동 하이라이트로 "이 거울을 탭해보세요" 유도

## Godot 4.2에서 추가로 확인할 항목

1. `Main.tscn` 실행 시 메뉴 카드가 먼저 표시되는지
2. 메뉴 -> 플레이 -> 성공/실패 -> 재시작/다음 구획 -> 캠페인 재플레이 흐름이 실제로 끊기지 않는지
3. Android 실기기에서 세로 레이아웃과 터치 반응이 자연스러운지
