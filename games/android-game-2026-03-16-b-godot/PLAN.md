# PLAN

## 2026-03-17 기준 현재 상태

이 프로젝트의 우선 목표는 “짧지만 상업적으로 보이는 세로형 모바일 퍼즐 게임”으로 첫인상과 기본 루프를 완성하는 것이었고, 이번 작업에서 그 범위를 실제 플레이 가능한 수준까지 끌어올렸습니다.

## 이번 작업으로 끝낸 항목

- 시작 시 바로 플레이로 떨어지지 않고 메뉴 카드에서 캠페인을 시작하도록 흐름을 수정
- `메뉴 -> 플레이 -> 성공/실패 결과 -> 다음 구획/재시도 -> 캠페인 재플레이` 루프를 단일 상태 흐름으로 정리
- 결과 카드를 전면 오버레이로 분리해 모바일에서 더 명확한 모달 흐름 확보
- `make_input_local()` 기반 터치 좌표 처리로 Android/Control 레이아웃 오프셋에 덜 취약한 입력 경로로 교체
- HUD를 목표 카드 + 3개 상태 카드 구조로 재배치하고 버튼, 패널, 오버레이 스타일을 전면 리스킨
- 보드 드로잉을 유리 재질, 광선 글로우, 광원 화살표, 더 강한 꽃/거울/차단물 실루엣으로 강화
- 배경을 온실 아치, 광선 샤프트, 잎 패턴, 비네트가 있는 장면형 배경으로 교체
- Godot 4.2.2 headless에서 실제 로드 및 핵심 루프 검증 스크립트 실행

## 현재 게임 루프

1. 메뉴 카드에서 현재 구획의 톤, 규칙, 목표 정보를 확인한다.
2. `플레이 시작` 또는 `이어하기`로 퍼즐 보드에 진입한다.
3. 거울을 탭해 광선을 정렬하고 모든 꽃을 개화시킨다.
4. 실패하면 전면 결과 카드에서 즉시 재도전하거나 메뉴로 돌아간다.
5. 성공하면 다음 구획으로 이동하거나 같은 퍼즐을 다시 풀 수 있다.
6. 마지막 구획을 끝내면 캠페인을 처음부터 다시 시작할 수 있다.

## 남아 있는 제품화 과제

- 실기기(Android)에서 프레임 유지와 세이프 에어리어를 확인하는 QA
- 사운드, 햅틱, 저장/이어하기
- 레벨 볼륨 확장 또는 챕터 구조 도입
- 결과 등급, 최소 회전 도전, 레벨 선택 같은 장기 반복 동기
