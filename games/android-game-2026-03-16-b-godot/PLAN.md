# PLAN

## 목표

이 프로젝트의 목표는 이전 산출물의 빠른 반사신경형 아케이드 축에서 벗어나, 작은 팀이 만들 수 있는 프리미엄 모바일 퍼즐 감성을 Godot 4로 구현하는 것입니다.

## 핵심 경험

- 손가락 한 번으로 조작 가능한 직관성
- 짧은 플레이에도 완성감이 느껴지는 레벨 클리어 구조
- 과장된 네온 대신 차분하고 고급스러운 온실 미감
- 규칙은 단순하지만 경로를 읽는 사고가 필요한 퍼즐 밀도

## 핵심 루프

1. 광원과 꽃의 위치를 읽는다.
2. 거울 타일의 초기 배치를 확인한다.
3. 필요한 타일만 회전해 빛의 경로를 정렬한다.
4. 모든 꽃을 개화시키고 다음 구획으로 이동한다.

## 시스템 범위

- 거울 회전
- 광선 경로 계산
- 꽃 개화 상태 판정
- 제한 회전 수
- 5개 수작업 레벨
- 재시작 / 다음 레벨 전환

## 비주얼 방향

- 저채도 짙은 녹색 배경
- 반투명한 유리 셀과 은은한 금속 프레임
- 황금빛 및 청백색 광원
- 단순하지만 촉감이 느껴지는 패널 UI

## 확장 아이디어

- 색상 필터 유리와 다중 광선 퍼즐
- 일일 퍼즐 모드
- 햅틱과 사운드 레이어
- 레벨 셀렉트와 별 3개 평가 시스템
