# PLAN

## 현재 목표

이 프로젝트는 짧은 세션 안에 규칙을 이해하고 끝까지 한 바퀴 돌릴 수 있는 모바일 퍼즐 게임으로 완성도를 올리는 데 초점을 둡니다.

## 구현 완료 상태

- 메뉴에서 현재 구획과 규칙을 확인하고 시작 가능
- 플레이 중 HUD에서 구획, 남은 회전, 개화 수, 목표 진행도 확인 가능
- 성공 시 결과 카드에서 다음 구획 이동 또는 재도전 가능
- 실패 시 결과 카드에서 즉시 재도전 또는 메뉴 복귀 가능
- 마지막 구획 완료 후 캠페인 처음부터 재플레이 가능
- 모든 레벨이 제한 회전 수 안에서 해법을 가짐

## 현재 게임 루프

1. 메뉴 카드에서 규칙과 현재 진행 구획을 확인한다.
2. 퍼즐 보드에서 거울을 회전해 빛의 경로를 정렬한다.
3. 모든 꽃을 피우면 결과 카드에서 다음 구획으로 이동한다.
4. 회전 수를 소진하면 같은 구획을 다시 시도한다.
5. 다섯 번째 구획까지 완료하면 캠페인을 처음부터 다시 돌릴 수 있다.

## 남아 있는 비핵심 확장 요소

- 저장/이어하기 영속화
- 사운드와 햅틱
- 레벨 선택 화면
- 별점 또는 최소 회전 기반 평가 시스템
