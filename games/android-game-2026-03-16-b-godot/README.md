# Glass Garden

`Glass Garden`은 Godot 4.2 계열을 기준으로 정리한 세로형 모바일 퍼즐 게임입니다. 플레이어는 유리 거울 타일을 회전시켜 빛의 경로를 연결하고, 각 온실 구획의 꽃을 모두 피워 캠페인을 끝까지 복원합니다.

## 현재 플레이 흐름

1. 실행하면 메뉴 카드가 먼저 열리고 현재 구획, 규칙, 목표를 보여줍니다.
2. `플레이 시작` 또는 `이어하기`로 게임에 진입합니다.
3. 보드에서 거울 타일을 탭해 90도씩 회전시키고 모든 꽃을 개화시킵니다.
4. 실패하면 결과 카드에서 `다시 시도` 또는 `메뉴`를 선택합니다.
5. 성공하면 `다음 구획` 또는 `한 번 더`를 선택합니다.
6. 마지막 구획 완료 후에는 `처음부터` 캠페인을 다시 시작할 수 있습니다.

## 핵심 규칙

- 광원은 보드 바깥에서 들어옵니다.
- 빈 칸은 빛이 직진 통과합니다.
- 거울은 탭할 때마다 90도 회전합니다.
- 차단 유리는 빛을 흡수합니다.
- 잠긴 거울은 회전할 수 없습니다.
- 제한 회전 수 안에 모든 꽃을 피우지 못하면 실패입니다.

## 이번 버전의 개선 포인트

- 메뉴, 결과, 재시도, 다음 구획, 캠페인 재플레이까지 전체 루프를 끊김 없이 정리
- Android 터치 좌표를 로컬 좌표로 변환하도록 입력 경로 수정
- 전면 결과 모달, 강화된 버튼 위계, 더 선명한 HUD 카드 구성
- 유리 재질 보드, 광선 글로우, 광원 화살표, 더 큰 꽃/거울 실루엣
- 온실 아치, 잎 패턴, 대각선 광선이 들어간 장면형 배경

## 실행 방법

1. Godot 4.2 이상에서 이 폴더를 Import 합니다.
2. 메인 씬은 `res://scenes/Main.tscn`입니다.
3. 에디터의 Play 버튼으로 바로 실행할 수 있습니다.

## 헤드리스 검증

이 저장소에는 핵심 루프를 점검하는 `res://scripts/headless_validation.gd`가 포함되어 있습니다.

예시:

```bash
godot4 --headless --path . --script res://scripts/headless_validation.gd
```

검증 스크립트는 아래를 확인합니다.

- 시작 시 메뉴가 먼저 열리는지
- 메뉴에서 플레이로 진입하는지
- 게임 진입 후 스크린 터치가 실제로 거울 회전으로 처리되는지
- 메뉴 복귀 및 이어하기가 동작하는지
- 실패 후 재시도, 성공 후 다음 구획, 캠페인 완료 후 재플레이가 이어지는지

## Android 메모

- 프로젝트는 세로 화면(`1080x1920`) 기준입니다.
- 모바일 렌더러를 사용합니다.
- 한 손 터치 플레이를 전제로 UI를 구성했습니다.
- 실기기 QA는 아직 별도로 필요합니다.
