# Glass Garden

`Glass Garden`은 Godot 4.2 기준으로 정리한 세로형 모바일 퍼즐 게임 프로토타입입니다. 플레이어는 거울 타일을 회전시켜 빛의 경로를 연결하고, 각 구획의 꽃을 모두 피워 유리 온실을 복원합니다.

## 현재 플레이 흐름

1. 시작 시 메뉴 카드에서 규칙과 현재 구획 정보를 확인합니다.
2. `플레이 시작` 또는 `이어하기`로 보드에 진입합니다.
3. 거울 타일을 탭해 90도씩 회전시키고 모든 꽃을 개화시킵니다.
4. 성공 시 결과 카드에서 `다음 구획`, `한 번 더`, `메뉴` 흐름을 선택합니다.
5. 실패 시 `다시 시도` 또는 `메뉴`로 돌아가 재도전합니다.
6. 마지막 구획 완료 후에는 캠페인 종료 카드에서 `처음부터` 다시 플레이할 수 있습니다.

## 핵심 규칙

- 광원은 보드 바깥에서 들어옵니다.
- 빈 칸은 빛이 직진 통과합니다.
- 거울은 탭할 때마다 90도 회전합니다.
- 검은 차단 유리는 고정되어 있으며 빛을 흡수합니다.
- 잠긴 거울은 회전할 수 없습니다.
- 제한 회전 수 안에 모든 꽃을 피우지 못하면 실패입니다.

## 포함된 게임 요소

- 수작업 퍼즐 5개
- 메뉴, 플레이, 성공/실패 결과, 캠페인 재시작까지 이어지는 전체 루프
- 남은 회전 수, 개화 수, 목표 진행도, 실시간 피드백 HUD
- 탭 반응에 맞춘 보드 펄스 피드백
- 배경 연출과 패널 스타일이 적용된 모바일 UI

## 실행 방법

1. Godot 4.2 이상에서 이 폴더를 Import 합니다.
2. 메인 씬은 `res://scenes/Main.tscn`입니다.
3. 에디터의 Play 버튼으로 바로 실행할 수 있습니다.

## Android 기준 메모

- 프로젝트는 세로 화면 기준(`1080x1920`)으로 맞춰져 있습니다.
- 렌더링 모드는 모바일 렌더러를 사용합니다.
- 한 손 터치 플레이를 전제로 UI가 구성되어 있습니다.
