# Gravity Well — 게임 디자인 플랜

## 핵심 재미 루프 (Core Fun Loop)

**30초 안에 빠져드는 구조:**
1. 별이 떨어진다 → 직관적 위기감
2. 탭 한 번으로 중력 우물 배치 → 즉각적 피드백
3. 별의 궤도가 휘어진다 → "와, 진짜 끌려간다!" 감탄
4. 타겟 영역에 안착 → 점수 + 시각 이펙트 보상
5. 연속 포획 → 콤보 배율 + 슬로모션 → 뇌에 도파민 분사

**핵심 판단 레이어:**
- **위치 판단**: 어디에 우물을 놓아야 별의 궤도를 원하는 곳으로 구부릴 수 있는가?
- **타이밍 판단**: 언제 놓아야 최대 효과를 발휘하는가?
- **모드 판단**: 인력 vs 척력, 상황에 맞는 모드 선택
- **자원 관리**: 제한된 우물 수로 최대 포획률 달성
- **우선순위**: 고점수 별(다이아몬드 300점) vs 쉬운 별(금별 100점), 콤보 유지 vs 안정 포획

## 게임 느낌 (Game Feel)

### 물리 피드백
- 별의 궤도가 중력장에 의해 부드럽게 곡선을 그림
- 루비별은 더 강하게 끌림 → 무거운 느낌
- 다이아몬드별은 빠르고 가벼움 → 까다로운 느낌
- 벽 바운스로 예측 불가한 궤도 생성

### 시각 피드백
- 별 꼬리 효과(trail)로 궤도 시각화
- 중력 우물 맥동 애니메이션
- 포획 시 파티클 폭발 이펙트
- 콤보 5x 이상 시 슬로모션 + 보라색 인디케이터
- 콤보 3x 이상 시 화면 흔들림

### 진행 긴장감
- 레벨마다 별 수 증가 + 속도 증가
- 높은 레벨에서 희귀 별 등장 확률 상승
- 타겟 영역 수 증가 (최대 4개)
- 우물 수도 함께 증가하여 압도감 방지

## 리텐션 전략

### 단기 (세션 내)
- 레벨 클리어 목표 (40% 이상 포획)
- 콤보 시스템으로 "한 판만 더" 심리
- 퍼펙트 보너스 (100% 포획 시 레벨×1000점)
- 최고 기록 갱신 알림

### 중기 (세션 간)
- 최고 점수 영구 저장
- 레벨이 올라갈수록 새로운 별 종류 해금
- 점점 더 복잡해지는 타겟 배치
- "이번엔 레벨 10까지!" 목표 설정 심리

### 장기
- 무한 레벨 진행 → 개인 한계 도전
- 별 종류 마스터 (다이아몬드 연속 포획)
- 순수 실력 기반 → 연습하면 확실히 느는 구조

## 프리미엄 앱 근거

### 왜 유료인가
- **광고 없음**: 집중력이 핵심인 퍼즐 게임에서 광고는 몰입 파괴
- **IAP 없음**: 실력 기반 게임에 과금 부스터는 성취감 훼손
- **완전한 경험**: 설치 즉시 모든 콘텐츠 이용 가능
- **존중하는 디자인**: 플레이어의 시간과 돈을 모두 존중

### 가격 정당성
- 독창적 물리 메카닉 (인력/척력 이중 시스템)
- 무한 리플레이 가치
- 배터리 효율적 (Canvas 기반 경량 렌더링)
- 오프라인 완전 지원

## 기술 설계 원칙

1. **불변 상태**: GameState는 data class, 매 프레임 새 인스턴스 생성
2. **순수 함수**: GameLogic의 모든 함수는 부수효과 없음
3. **단일 진실 원천**: 화면 크기, 점수, 게임 진행 모두 GameState에 집중
4. **프레임 독립**: deltaTime 기반 업데이트로 기기 성능 차이 흡수
5. **최소 의존성**: Jetpack Compose 외 추가 라이브러리 없음
