# Market Benchmark — Gravity Well

## 경쟁작 분석

### 1. Orbit (궤도 퍼즐)
- **장르**: 중력 시뮬레이션 퍼즐
- **강점**: 아름다운 궤도 시각화, 교육적 가치
- **약점**: 실시간 액션 부족, 반복 플레이 동기 약함
- **채택**: 중력 물리 시각 피드백 (궤도 곡선, 중력장 시각화)
- **회피**: 정적인 퍼즐 형식 → 실시간 액션으로 긴장감 확보

### 2. Osmos (삼투)
- **장르**: 물리 기반 전략
- **강점**: 독창적 크기 흡수 메카닉, 명상적 분위기
- **약점**: 느린 페이스, 초반 진입 장벽 높음
- **채택**: 물리 기반 조작의 직관적 쾌감
- **회피**: 느린 템포 → 별 낙하로 자연스러운 긴장감 생성

### 3. Fruit Ninja
- **장르**: 아케이드 액션
- **강점**: 즉각 피드백, 30초 만에 재미 전달, 누구나 이해하는 조작
- **약점**: 깊이 부족, 전략 요소 빈약
- **채택**: "탭 한 번으로 시작되는 재미" 원칙, 화면 이펙트 보상감
- **회피**: 단순 반복 → 인력/척력 전환 + 자원 관리로 전략 깊이 추가

### 4. Alto's Odyssey
- **장르**: 무한 러너
- **강점**: 시각 디자인 완성도, 선셋 분위기, 유료 모델 성공 사례
- **약점**: 능동적 전략 판단 부족
- **채택**: 프리미엄 유료 앱 모델, 분위기 있는 시각 디자인 (우주 테마)
- **회피**: 수동적 조작 → 매 순간 판단이 필요한 능동적 게임플레이

### 5. Geometry Wars (Touch)
- **장르**: 트윈스틱 슈터
- **강점**: 파티클 폭발 쾌감, 네온 시각 스타일, 콤보 시스템
- **약점**: 조작 복잡도, 하드코어 편향
- **채택**: 네온 컬러 팔레트, 파티클 이펙트 보상, 콤보 배율 시스템
- **회피**: 복잡한 조작 → 단일 탭 + 모드 전환 버튼으로 단순화

## 차별화 포인트

| 요소 | 기존 게임들 | Gravity Well |
|------|------------|--------------|
| 입력 방식 | 스와이프/드래그/이중스틱 | 단일 탭 (배치) + 모드 전환 |
| 물리 활용 | 장식적 / 없음 | 핵심 메카닉 (인력/척력) |
| 전략 깊이 | 반사신경 위주 | 위치 + 타이밍 + 자원 관리 |
| 시각 보상 | 파괴 이펙트 | 궤도 곡선 + 포획 이펙트 |
| 세션 길이 | 30초~5분 | 30초~3분 (레벨당) |

## 타겟 가격대

- **$2.99 USD** (프리미엄 유료)
- 근거: Osmos($2.99), Alto's Odyssey($4.99), Monument Valley($3.99) 등 인디 퍼즐 프리미엄 가격대
- 무료 체험 없이 완전한 경험 제공
- 리뷰/평점 기반 자연 유입 목표
