# Chain Reactor — 게임 디자인 플랜

## 핵심 컨셉

**"한 번의 탭이 만드는 폭발의 도미노"**

제한된 스파크로 떠다니는 오브들 사이에 폭발을 전략적으로 배치하여
최대한 긴 연쇄 반응을 만들어내는 퍼즐 아케이드 게임.

## 첫 30초 경험 설계

1. **0~3초**: 화면 가득 떠다니는 네온 오브들이 눈을 사로잡음
2. **3~5초**: "⚡ 3" 표시 → 3번 탭할 수 있다는 직관적 이해
3. **5~8초**: 첫 탭 → 폭발 → 가까운 오브 연쇄 폭발 (시각적 보상)
4. **8~15초**: "어디를 탭해야 가장 많이 터질까?" — 전략적 사고 시작
5. **15~25초**: 두 번째, 세 번째 스파크 사용 → 체인 콤보 쌓이며 점수 급증
6. **25~30초**: 라운드 결과 → "다음 라운드는 더 많은 오브!" — 도전 욕구

## 판단 레이어 (5가지 결정 포인트)

1. **위치 선택**: 오브 밀집 지역 파악 → 어디를 탭할 것인가?
2. **타이밍**: 오브가 이동하므로 밀집 순간을 포착
3. **순서 전략**: 메가 오브 근처를 먼저 터뜨려 폭발 범위 극대화
4. **스파크 분배**: 3~6개 스파크를 어떻게 분배할 것인가?
5. **특수 오브 활용**: 스플리터 → 파편으로 멀리 있는 오브까지 도달

## 프리미엄 유료 앱 근거

### 왜 유료인가?
- **광고 없음**: 폭발 연쇄 반응의 몰입감을 광고가 방해하면 핵심 재미 파괴
- **인앱 구매 없음**: "스파크 추가 구매" 같은 P2W 요소는 전략 게임의 본질을 훼손
- **완결된 경험**: $2.99에 무한 리플레이 가치 제공

### 유료 정당성
- 매 판마다 다른 오브 배치 → 무한한 전략 변화
- 라운드 진행형 난이도 → 장기 도전 목표
- 최고 체인/점수 기록 경쟁 → 자기 자신과의 대결

## 리텐션 설계

### 세션 내 리텐션 (30초~3분)
- 라운드마다 "조금만 더" 효과 (오브 증가 + 스파크 증가)
- 체인 콤보의 시각적/청각적 피드백 강화
- 슬로우 모션 → 대규모 체인의 극적 연출

### 일간 리텐션
- 최고 점수/최대 체인 기록 갱신 욕구
- "오늘은 라운드 몇까지 갈 수 있을까?"
- 짧은 세션 → 틈새 시간에 한 판

### 장기 리텐션
- 라운드 10+ 도달 시 특수 오브 조합 등장
- 퍼펙트 클리어 연속 달성 챌린지
- 체인 x10 달성 → 마스터리 목표

## 기술 아키텍처

### 상태 관리
- `GameState` 불변 데이터 클래스 → `copy()` 기반 업데이트
- 순수 함수 `update()` → 부작용 없는 게임 로직
- Compose Canvas → 60fps 프로시저럴 렌더링

### 충돌 감지
- 원형 기반 거리 계산 (O(n*m), n=폭발, m=오브)
- 연쇄 폭발 → 폭발 큐 → 프레임 단위 전파

### 렌더링 파이프라인
1. 배경 (방사형 그라데이션 + 성운)
2. 별 (트윙클 애니메이션)
3. 오브 (글로우 + 그라데이션 + 타입 인디케이터)
4. 폭발 (링 + 코어 플래시)
5. 파편 (프로젝타일)
6. 파티클
7. 점수 팝업
8. HUD

## 확장 가능성

1. **챌린지 모드**: "스파크 1개로 20개 오브 폭파" 등 퍼즐 스테이지
2. **데일리 챌린지**: 매일 고정된 오브 배치 → 글로벌 랭킹
3. **신규 오브 타입**: 블랙홀 (흡인), 미러 (폭발 반사), 타임 (시간 되감기)
4. **테마 스킨**: 우주/해양/화산 등 비주얼 변경
