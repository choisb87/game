# Chain Reactor — 마켓 벤치마크

## 경쟁작 분석

### 1. Boomlings (Geometry Dash 제작사)
- **장르**: 탭 기반 체인 리액션
- **강점**: 심플한 조작, 중독성 있는 피드백
- **약점**: 콘텐츠 업데이트 부족, 반복적
- **참고**: 원탭 조작의 직관성

### 2. Atomic Fusion
- **장르**: 원자 합성 퍼즐
- **강점**: 과학적 테마, 체인 반응 메카닉
- **약점**: 진입 장벽 높음, UI 복잡
- **참고**: 체인 반응의 시각적 만족감

### 3. Fruit Ninja
- **장르**: 슬라이스 아케이드
- **강점**: 30초 훅 완벽, 촉감 피드백
- **약점**: 광고 과다, IAP 의존
- **참고**: 즉각적 시각 피드백, 콤보 시스템

### 4. Orbital 1
- **장르**: 턴 기반 전략 아케이드
- **강점**: 깊은 전략성, 리플레이 가치
- **약점**: 학습 곡선, 세션 길이 김
- **참고**: 제한된 자원으로 최적 전략 찾기

### 5. Geometry Wars 3
- **장점**: 파티클 이펙트, 네온 비주얼
- **약점**: 조작 복잡, 모바일 최적화 부족
- **참고**: 네온 비주얼과 폭발 이펙트의 시각적 쾌감

## 채택할 요소

1. **Fruit Ninja의 즉각적 피드백**: 탭 → 폭발 → 연쇄 반응의 0.1초 이내 시각적 응답
2. **Orbital의 전략 깊이**: 제한된 스파크로 최적 위치 계산
3. **Geometry Wars의 네온 미학**: 어두운 배경 + 발광 오브 + 파티클 폭발
4. **Boomlings의 원탭 접근성**: 한 손 조작, 즉시 이해 가능한 룰
5. **콤보 시스템의 보편성**: x1→x10 멀티플라이어로 "더 높은 체인" 도전 욕구

## 피해야 할 요소

1. **광고 인터럽트**: 연쇄 반응의 몰입을 광고로 끊으면 핵심 재미 파괴
2. **복잡한 튜토리얼**: 첫 탭에서 바로 이해되어야 함 (별도 튜토리얼 불필요)
3. **과도한 UI**: 게임 화면에 버튼/메뉴 최소화, 풀스크린 캔버스 경험
4. **P2W 요소**: 스파크 추가 구매 같은 밸런스 파괴 요소
5. **긴 세션 강요**: 한 판 30초~3분, 언제든 끊을 수 있는 구조

## 경쟁 우위

1. **독특한 핵심 루프**: "전략적 폭발 배치 + 연쇄 반응 관전" — 기존 게임에 없는 조합
2. **극적 연출**: 대규모 체인 시 슬로우 모션 + 화면 흔들림 + 파티클 폭풍
3. **깊은 리플레이**: 랜덤 오브 배치로 매번 다른 전략 필요
4. **프리미엄 품질**: 광고/IAP 없는 깔끔한 경험
5. **접근성**: 한 손 탭 조작, 5초 만에 규칙 이해, 평생 마스터
