# Market Benchmark — 벽돌깨기/아케이드 장르 분석

## 차트 상위 레퍼런스

### 1. Brick Breaker Star (4.5★, 10M+ DL)
- **채택**: 직관적 원터치 조작, 다양한 레벨 패턴
- **회피**: 과도한 광고 빈도 (매 3레벨마다 전면 광고)
- **교훈**: 핵심 메커닉이 탄탄하면 단순해도 성공

### 2. Atari Breakout (4.3★, 5M+ DL)
- **채택**: 클래식 벽돌깨기 감성의 현대적 리메이크 접근
- **회피**: 레트로 감성에만 의존 → 비주얼 차별화 부족
- **교훈**: 브랜드 없이도 비주얼 품질로 승부 가능

### 3. Neon Ball (4.4★, 1M+ DL)
- **채택**: 네온 비주얼 테마가 아케이드와 잘 맞음
- **회피**: 게임플레이 깊이 부족 (단순 반복)
- **교훈**: 비주얼 + 게임 깊이 모두 필요

### 4. Geometry Wars 3 ($4.99, 유료 프리미엄)
- **채택**: 프리미엄 가격 모델 + 네온 비주얼 = 높은 유저 만족
- **회피**: 진입 장벽이 높은 복잡한 조작
- **교훈**: 유료 아케이드도 네온 테마면 시장성 있음

### 5. PAC-MAN Party Royale (Apple Arcade)
- **채택**: 클래식 IP의 모던 리바이벌 성공 사례
- **회피**: 멀티플레이어 의존도
- **교훈**: 아케이드 장르는 모바일에서 여전히 강력

## 장르 트렌드 (2025-2026)

| 트렌드 | 적용 |
|--------|------|
| 짧은 세션 선호 | ✅ 3-8분 세션 설계 |
| 광고 피로감 증가 | ✅ 프리미엄 유료 모델 |
| 비주얼 차별화 | ✅ 네온 글로우 + 파티클 |
| 원핸드 조작 | ✅ 드래그 + 탭만 사용 |
| 콤보/연쇄 시스템 | ✅ 콤보 배율 + 화면 이펙트 |

## 경쟁 우위 포인트

1. **순수 Compose 네이티브**: 부드러운 60fps, 낮은 배터리 소모
2. **네온 브레이커 정체성**: 사이버펑크 아케이드 감성
3. **광고 제로**: 유저 경험 최우선
4. **즉시 재미**: 튜토리얼 없이 바로 플레이 가능
5. **깊이 있는 진행**: 무한 레벨 + 콤보 마스터리

## 피해야 할 것

- ❌ 에너지/스태미나 시스템 (유료 앱에서 이중 과금 느낌)
- ❌ 과도한 UI 팝업 (평가 요청, 소셜 공유 강요)
- ❌ 필수 튜토리얼 (즉시 플레이 가능해야 함)
- ❌ P2W 요소 (프리미엄 앱 신뢰 훼손)
