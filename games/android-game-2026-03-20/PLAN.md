# Neon Breaker — 게임 디자인 플랜

## 핵심 재미 루프 (Fun Loop)

1. **즉각적 이해**: 화면 탭 → 공 발사 → 벽돌 부서짐 (2초 내 핵심 메커닉 습득)
2. **콤보 쾌감**: 연속 타격 시 콤보 카운터 + 점수 배율 증가 → 도파민 트리거
3. **파워업 기대감**: 벽돌 파괴 시 18% 확률로 파워업 드롭 → 수집 욕구
4. **레벨 진행**: 클리어 → 새로운 패턴 + 난이도 증가 → "한 판 더" 동기

### 30초 훅 설계

- 0-2초: 네온 비주얼로 시각적 임팩트
- 2-5초: 탭하여 공 발사, 벽돌 파괴 시 파티클 + 화면 흔들림
- 5-15초: 첫 콤보 달성 + 파워업 획득
- 15-30초: 레벨 1 클리어 or 생명 잃고 재도전 욕구

## 리텐션 전략

| 요소 | 설계 |
|------|------|
| 단기 (세션 내) | 콤보 시스템, 파워업 체이닝, 레벨 클리어 보상감 |
| 중기 (일주일) | 레벨 진행도, 최고 기록 갱신 욕구 |
| 장기 (한달+) | 무한 레벨, 난이도 커브로 마스터리 동기 |

## 유료 앱 근거 (Premium Rationale)

### 왜 유료 모델인가

1. **광고 없는 몰입**: 벽돌깨기는 집중 플로우가 핵심. 광고 삽입은 플로우 파괴
2. **공정한 밸런스**: IAP 없이 모든 콘텐츠 접근 → 유저 신뢰
3. **세션 최적화**: 광고 시청 유도 없이 순수 게임플레이 최적화 가능

### 가격 전략

- 권장가: $1.99 ~ $2.99
- 할인 진입: 출시 1주 $0.99 프로모션
- 가치 제안: "광고 없는 네온 아케이드 — 한번 구매, 영원히 즐기기"

## 세션 길이 분석

- 최소 세션: 2-3분 (지하철 한 정거장)
- 최적 세션: 5-8분 (점심시간 짬)
- 최대 세션: 15-20분 (고레벨 도전)
- 모바일 유저 행동 패턴과 정확히 일치
